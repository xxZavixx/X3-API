Quick Start

Endpoint: POST https://alpha.x3digitalcapital.com/api/v1/x402/analyze

Payment: x402 (USDC on Base) · Price: $0.12 per call

Required fields: symbol, direction, entry, exit, qty

No rate limits · No quotas · Unlimited calls

1. Make your first API call with x402

Use x402-fetch (Node.js) or x402-python (Python) to handle payment. First call returns HTTP 402 with payment instructions:

// JavaScript with x402-fetch
import { x402Fetch } from 'x402-fetch';

const result = await x402Fetch(
  'https://alpha.x3digitalcapital.com/api/v1/x402/analyze',
  {
    walletPrivateKey: process.env.WALLET_KEY,
    chain: 'base', // Base network for USDC
    method: 'POST',
    body: {
      trades: [
        {
          symbol: 'XRP',
          direction: 'long',
          entry: 0.5,
          exit: 1.2,
          qty: 100,
          date: '2026-08-09',
          notes: 'Breakout trade'
        }
      ]
    }
  }
);

console.log(result);

2. Request format & x402 payment

Payment Method: First request to /api/v1/x402/analyze returns HTTP 402 with payment instructions. Send USDC to the address, retry with payment proof, get your analysis.

Required fields per trade:

  • symbol (string): Ticker symbol (e.g., "XRP", "BTC", "ETH")
  • direction (string): "long" or "short"
  • entry (number): Entry price
  • exit (number): Exit price
  • qty (number): Quantity traded (must be > 0)

Optional fields (improve analysis):

  • date (string): Trade date (YYYY-MM-DD)
  • notes (string): Entry/exit reasoning, setup, market context

Limits: Up to 100 trades per request · No rate limits · Unlimited calls

3. Understanding the response

Metrics (calculated):

  • netPL: Total profit/loss across all trades
  • winRate: Percentage of winning trades (0-100)
  • profitFactor: Sum of wins ÷ sum of losses. >1 is profitable.
  • avgWin: Average profit on winning trades
  • avgLoss: Average loss on losing trades

AI Scores (0-100):

  • overall: Overall trading quality
  • riskManagement: How well you control losses
  • consistency: Trade-to-trade reliability
  • discipline: Following methodology without emotion
  • edgeClarity: How repeatable your edge is

Grade: A (90+), B (80+), C (70+), D (60+), F (<60)

Risk Flags: Severity-ranked (high/medium/low) alerts for missing stops, tiny samples, no dates, etc.

Recommendations: Prioritized actions to improve your trading.

4. Error responses

Invalid trade data:

{
  "error": "invalid_trade",
  "message": "Each trade needs: symbol, direction, entry, exit, qty"
}

Payment required (x402):

HTTP 402 Payment Required
{
  "error": "payment_required",
  "message": "Send $0.12 USDC to address below, then retry",
  "x402": {
    "price": "$0.12",
    "network": "base",
    "paymentAddress": "0x...",
    "stablecoin": "USDC"
  }
}

Insufficient payment:

{
  "error": "insufficient_payment",
  "message": "Payment received but amount is less than $0.12"
}
